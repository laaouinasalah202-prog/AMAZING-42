🛠️ Config file:
This section describes the configuration file.
WIDTH – the width of the maze
HEIGHT – the height of the maze
ENTRY – starting point of the maze
EXIT – exit point of the maze
OUTPUT_FILE – file containing the maze in hexadecimal
PERFECT – this is a flag. If true, there will be a single path between entry and exit. Otherwise, there will be two paths.
SEED – the initial value used to initialize a pseudo-random number generator for maze generation

🧩 Maze Generation Algorithms Chosen:
Backtracking Algorithm:
A backtracking (DFS) maze is generated by starting from a cell and carving passages by moving to random unvisited neighbors, backtracking when no moves are available. This creates a perfect maze with long corridors, deep paths, and no loops, ensuring exactly one path between any two cells.

Prim's Algorithm:
A Prim’s algorithm maze is generated by starting from a single cell and gradually expanding the maze by randomly removing walls that connect the existing maze to unvisited cells. This process continues until all cells are connected, producing a perfect maze with no loops and exactly one path between any two points.

BFS (Finding the Shortest Path):
BFS is used to find the shortest path by expanding outward level by level from a starting cell, visiting unvisited neighbors in a queue-based order. This produces a perfect maze with many short paths and a more uniform, evenly distributed structure, ensuring exactly one path between any two cells.
